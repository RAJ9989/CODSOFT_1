# 🕵️ Network Packet Sniffer

> Captures and analyzes live network traffic in real-time — extracts source/destination IPs, protocols, payload, and displays everything in a clean table.

[![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](LICENSE)
[![Cybersecurity](https://img.shields.io/badge/Domain-Cybersecurity-red?style=flat-square)](https://github.com/RAJ9989)

## 🚀 Features

- ✅ Capture packets from a selected network interface
- ✅ Extract source & destination IP addresses
- ✅ Identify protocol (TCP, UDP, ICMP, etc.)
- ✅ Display packet size
- ✅ Extract limited packet payload/data
- ✅ Clean table-based output
- ✅ Stop capturing gracefully with `Ctrl+C`

## 📦 Installation

```bash
git clone https://github.com/RAJ9989/CODSOFT_1.git
cd CODSOFT_1
pip install scapy
python packet_sniffer.py
```

> ⚠️ **Note:** Requires administrator/root privileges to capture packets.
